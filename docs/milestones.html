The journey

Phase 1 · The foundation
The backbonev1.0.0Oct 21

A device protocol, a registry, a request router, a model gateway over Ollama, and an HTTP API — the brain and plumbing, with no hardware yet.

62 tests, live-verified
Phase 2 · Real hardware
Devices come alivev2.0 – v2.3Oct 21

Device agents ran on a real Raspberry Pi and ESP32. Commands travelled end-to-end — dashboard to laptop to device and back — with auto-discovery, heartbeats, and a first web panel. Chat sped up 10–40× by keeping one model warm.

LLM → device confirmed on hardware
Senses and signalsv2.4 – v2.7Oct 22

The ESP32 gained a temperature sensor, an OLED screen, a buzzer and a light; the Pi gained a 3.5" screen and touch pads. Over-the-air firmware updates and device-to-device commands followed.

DHT11, OLED, TFT, touch all working
It listensv2.8.0Oct 22

The voice loop: press a touch pad, speak, and the Pi records it, the laptop transcribes and answers, and the reply lands on the Pi's screen.

verified with real speech
A face and a voicev2.9 – v2.10Oct 23

The Pi screen became an animated bot face — calm, talking, alert, asleep — with the live reading, the device list and the latest answer laid out around it.

rendered and tuned on the panel
The brain grows upv2.11 – v2.13Oct 23

Room-aware answers (it reads the sensor when you ask about the room), a web control panel with streaming replies, auto-start at logon, and smarter model choice that stopped wasting 10–40s on needless model swaps.

"28.5°C" instead of "I can't sense that"
It seesv2.14 – v2.16Oct 23

Vision arrived from four sources — photo upload, laptop webcam, Pi webcam, and voice — plus a mic in the browser. Touch pad 3 shows the live camera on the screen and describes the snapshot when you let go.

webcam snapshot described live
Hardened and provenv2.17 – v2.18Oct 23

A developer page, a security pass (every endpoint keyed, the key kept off the network, the AI unable to command hardware), and a failure/recovery suite — the Pi agent recovers from a crash in 5 seconds.

recovery 11/13, security verified live
Clean and documentedv2.18.1 – v2.20Oct 23

Personal information scrubbed from the entire git history, a rewritten README, a code map from the graph, and a security report backed by live checks and a clean dependency audit.

0 secrets in history · 0 known CVEs

Where it stands now

Working, verified, and shipped

A local AI station you talk to, show photos to, and control from a web page — across a laptop, a Raspberry Pi and an ESP32, all on your own network. 100 automated tests and a full end-to-end pass on real hardware.

  • Still open: reflash the ESP32 to firmware 0.5 (one USB cable).
  • Still open: encrypt the MQTT traffic before trusting an unfamiliar network.
  • Not yet tested: recovery from broker restart, Wi-Fi loss, and Pi power loss.
  • By design: no emergency-stop yet — required only once a motor is added.
