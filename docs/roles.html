Roles this project speaks to

The local-ai-ecosystem build touches hardware, backend, AI and security at once, so it supports several career directions. Each role below is matched to the specific parts of the project that prove it — with an honest fit, not a wish list.

Fit reflects how directly the project demonstrates the role's core work. "Strong" = the project is solid portfolio evidence on its own; "Supporting" = it backs the role alongside other work.

How to present it

In a CV or interview

  • One line: "Built a fully local, three-device AI assistant (laptop + Raspberry Pi + ESP32) — voice, vision and sensors over MQTT, with a safety model that keeps the LLM out of the command path. 100 tests, live-verified, security-audited."
  • Lead with the role you're applying for — the same project is an embedded story, a backend story, or an AI story depending on which section above you open with.
  • Bring the evidence: the code map, the security report, and the milestone report make strong talking points — they show engineering judgement, not just a demo.
  • Be honest about scope — it's a personal project, not production at scale. That honesty reads as maturity.
